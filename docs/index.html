transcript.md
The transcript appears here once the recording stops.

Each line is labeled with its track: me for the mic, them for system audio.
me / them

Separate tracks, clear sides

Mic and system audio are recorded and transcribed on their own. The labels identify tracks, not individual people.

10 min

Stops when the room goes quiet

After ten silent minutes on both tracks, recording stops. A notification warns you a minute ahead, and any sound cancels it. Four hours is the hard cap.

--retry

Re-transcribe any time

Run betterMeet transcribe on an old session with another model or settings. The originals stay untouched, and failed tracks resume from checkpoints.

Plain files,
yours to keep.

Every session is a folder under ~/Recordings: the audio, a readable transcript, and a structured JSON version for your own tools. No database or export step, and nothing to sync.

Dictation

Hold a key.
Say it. Let go.

Put the cursor in any text field, in any app. Hold Right ⌥ and speak, and the words stream in as a live preview, then settle when you let go. The left Option key keeps working as usual.

Hold the key above, or Right ⌥ on your keyboard, to try it. Tap once to latch it on, and tap again to stop.

  • HoldPush-to-talk. Dictation runs while the key is down.
  • TapStays on until your next tap.
  • FallbackIf an app blocks insertion, the text goes to your clipboard.

One package

A recorder and a dictation tool.
One small binary.

Built to share

Meetings and dictation run on the same local engine. A dictation can run between the two meeting tracks, so you don't wait for the whole transcript.

Out of the way

No Dock icon and no main window. A LaunchAgent starts it at login, and the menu shows what it's doing: recording, transcribing a track, or dictating.

One file to install

The icons, the Info.plist and the permissions metadata are all compiled into a single executable in /usr/local/bin. There's no separate resource bundle to install.

Private by design

Your meetings stay on your Mac.

Speech is recognized on your Mac. Model weights download once, on first use, and after that your audio and transcripts stay in folders you own. You don't need an account or an API key.

Install

Build it. Blink. Done.

betterMeet builds from source with Swift 6. The steps below install the binary and a LaunchAgent that starts it at every login.

  1. Clone and build

    From the repository root. If you're updating, stop any recording and quit the app first.

  2. Install through a fresh file

    Replacing the running binary in place trips macOS code signing. Copying to a temporary file and moving it into place avoids that.

  3. Grant permissions

    Allow microphone and system audio the first time you record. Right ⌥ dictation also needs Accessibility and Input Monitoring.

  4. Look for the eye

    It's closed while idle and opens while it works.

zsh
$ git clone https://github.com/flup-repo/betterMeet.git
$ cd betterMeet
$ swift build -c release
$ sudo mkdir -p /usr/local/bin
$ tmp=$(sudo mktemp /usr/local/bin/betterMeet.XXXXXX) &&
    sudo install -o root -g wheel -m 755 .build/release/betterMeet "$tmp" &&
    sudo mv -f "$tmp" /usr/local/bin/betterMeet &&
    /usr/local/bin/betterMeet install --launch-at-login
~/.config/betterMeet/config.json · optional
{
  "mic_voice_processing": false,      // echo cancellation for speakers
  "dictation_max_seconds": 600,
  "inactivity_timeout_seconds": 600,  // auto-stop after silence
  "max_duration_seconds": 14400,      // 4 h hard cap
  "inference_idle_seconds": 300,      // keep models warm
  "transcription": {
    "model": "v3",                    // v3 multilingual · v2 English
    "speech_detection": "annotate"
  }
}
